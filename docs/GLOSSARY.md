# 术语速查

只收**本项目自造的机制词**——TCP/TLS/SNI 这类教科书基础词不收（README 与各文档首次出现处已就地解释）。数字全部与当前代码常量对齐（出处见表尾），机制条目以现行代码为准——本文件不收历史方案。

## 选路与通道

| 名词 | 大白话 |
| --- | --- |
| 二部图 | routes.json 的组织形式：左边 65 个 IP 节点、右边 25 个路由键，边 = "这个 IP 服务这些域名"。没有边就不能服务，这是数据约束 |
| 路由键 | `github.com` / `*.github.com` / `objects.githubusercontent.com` 这类条目。精确键覆盖自身+子域，`*.` 通配键只覆盖子域 |
| 四开关位 | 每个路由键的属性：`session`（带登录态，固定同一 IP）、`content`（可竞速可切片）、`big`（大文件/Release，挂大镜像链）、`direct`（不进代理） |
| 边 | 一个 (IP, 路由键) 组合——路由行为的最小记账单位。它的状态小黑屋三档见下条 |
| 边冷却 | 某条边的实测小黑屋，三档：响应 421 / 证书不匹配 → 4 小时；新拨连接超时/断连 → 120 秒；风控拦截页 → 600 秒。风控冷却只能到期自愈，不被"成功"洗白。**只有响应层会写边**：TLS 校验失败、TCP 连不上都不写边 |
| 死亡退避 | IP 级 TCP/TLS/h2 失败后的记账，串发/竞速跳过它 |
| 通道 | 一条 IP 上的 h2 连接。**每 IP 恒 1 条**，多域名靠 h2 `:authority` 多路复用 |
| 通道池 | 全仓唯一取连接的入口：要连接只找它，同 IP 已有通道直接复用 |
| 建造锁 | 同 host 取通道未命中只放一个进拨号（雷群去重），等锁者直接 await，最多等 15s |
| 闲置焚毁 | 通道空闲 10 秒销毁——这就是替代"定时探活"的机制，探活已整体移除 |
| 黑洞判定 | 响应头到了但 30 秒零数据字节 = 上游黑洞，判死换路 |
| 遥测拦截 | GitHub 前端埋点（`/_private/browser/*`、alive、collector）本地读掉回 204，零字节发往上游 |
| 拨号并发闸 | 真实流量的拨号总闸：同一时刻最多 48 个拨号在途——开个页面几十条连接并发要建连，没闸会打爆自己 |
| 伪装 SNI | 池内握手第一句写 `baidu.com` 等不受限域名，证书按 `verify` 锚点验证真 GitHub 证书——SNI 阻断不适用（MITM 模式） |
| 握手分片 | 透传（MITM 关）时把浏览器的 ClientHello 拆 2~3 段、首刀 1~16B 随机、段间隔 20~70ms 随机发送——DPI 单包拼不齐 SNI 就不会掐 |
| gh_defuse | 风控页化解：403 restricted / 400 Whoa 拦截页本地识别，(IP, 域名) 记 600s 风控冷却，换 IP 重试 |

## 加速管线

| 名词 | 大白话 |
| --- | --- |
| 镜像链 | 每种资源的"复印店优先级名单"。内置 6 家（gh-proxy 系），单链上限 5；名单来自 routes.json，可加自部署镜像。只对 GET/HEAD 的大文件与 Release 路径生效 |
| 直连腿 | 直连以 `direct/{host}` 身份参与切片竞速，与镜像一视同仁 |
| 切片前提 | GET、非探片、总长可探，且切片门=校准(未测>0 且候选全闲)或无 Range(原生浏览器)——任一不成立走单流；带 Range=下载器连接也单流。不再设 512KB 门槛：切片第一目的是测速/浏览器并行，门槛只会挡住小文件的校准 |
| 探片 | 无 Range 的请求先发 `bytes=0-0` 探总长；总长记 10 分钟，同 URL 下一条不必再探 |
| 段位 | 校准（未测镜像>0 且候选全闲）**或原生浏览器下载（无 Range）** → 每镜像一片（区间÷镜像数）；带 Range 的请求（下载器拆好的连接）单流直发 ECT 最优——并行度归下载器 |
| 刀口 | 段边界偏移。每段必须 206 且 Content-Range 起点对准刀口、终点不越界——错位 = 静默截断，按这家失败换下一个 |
| 停滞收尸 | 段停滞 5 秒零帧 → 慢段缩边界，已收字节留下、尾巴排补发（缓冲一个字节不丢）——真死片止损 |
| 重分配 | 测速完成后（切片起 350ms）每拍把剩余字节按各段实测速率摊派公平份额，超额 ≥ 128KB 的段切尾重派（流掐、h2 连接不断回池）；drain 最小者份额天然最大自动保留；切到份额后下一拍超额自然低于下限，无乒乓 |
| 补发 | 按偏移重拉尾巴；接手按 ECT 挑家（不能挑"最空闲"——刚断流负载归零恰是最空闲）；连续 6 次空手放弃 |
| ECT 双窗 | 派发打分：(在途字节+新请求)×窗口ms ÷ 上窗实收，真毫秒，最小者胜、无容差；零历史垫底（闲者先试）。分配窗 5ms（补发/重派新鲜度，零收沿用）、测速窗 350ms（单流新连接路由，零收有债清零）；每面源独立记账，独立线程 5ms 一拍 |
| 降权 | 镜像失败两档：硬错误（拒连/RST/坏回包）45 秒、超时类 15 秒——慢不等于死；切片首切/补发失败同样降权 |
| 熔断 | 镜像链整链全灭 → 60 秒快速失败；零镜像时直连独走不连坐 |
| 直连多路 | 媒体白名单 7 域（raw/user-images/private-user-images/media/camo/gist/avatars）的切片：探片 10KB 记总长，恒 4~8 段（目标 192KB）全部骑池内同一条通道并发拉，5s 界由镜像救援续传；185.199 聚合水管恒定，多连接不加吞吐 → 不参与重分配 |
| 身份头剥除 | 镜像/切片请求剥 Cookie / Authorization / Referer / UA，注入恒定浏览器 UA——账号凭据不外流，CF 系镜像拦非浏览器 UA |
| 总长记忆 | 探得/记忆的总长与 206 自报不符 = 记忆陈旧 → 作废回单流（对象换版/镜像转码） |

## 缓存

| 名词 | 大白话 |
| --- | --- |
| 资产库 | githubassets 的 js/css/字体按 URL 一存永逸，本地透明回放；15MB 池按文件年龄从旧到新淘汰。收录门：200 + js/css/字体；仓库页 html 一律不缓存（三次白屏教训，见 CACHE.md） |
| 时代中立 | URL 里的内容哈希就是内容指纹，同 URL 永远同字节；发版换哈希 = 新条目，库永远不会给错内容 |
| 骨架 | 首页框架页（`/`）跨会话缓存 7 天——纯框架页，数据全靠 XHR；超期交旧 + 后台静默重拉 |
| 会话缓存 | 列表页/搜索页会话内缓存，空闲 15 分钟清盘 |
| 身份标签 | 未登录固定一枚；登录 = `user_session` 值的摘要。同机两账号不串页 |
| SESSION_EPOCH | 会话号：首次导航写当前毫秒，间隔超 15 分钟 +1 并清会话条目；重启必新会话 |
| 闸门页 | 2FA 验证、密码确认、限流页——GitHub 拿这些顶替你请求的 URL，拒收 |
| 截断自愈 | 骨架条目缺结尾标记 → 当场删文件当 miss |
