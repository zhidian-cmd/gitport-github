# 术语速查

## 网络与封锁

| 名词 | 大白话 |
|---|---|
| 域名 / IP 地址 | 域名是"名字"，IP 是"门牌号"。`github.com` 是名字，`140.82.112.3` 是门牌 |
| DNS | 查号台：把名字翻译成门牌。查号台可被投毒（给你假门牌）——本程序不问它，内置了真门牌表 |
| TCP 连接 | 电话拨通。拨不通 = 这个 IP 当下不可用 |
| TLS 握手 / HTTPS | 电话接通后先对暗号、换加密频道，之后通话内容外人听不懂 |
| SNI | 握手第一句里**明文**写的"我要找 xx 域名"。审查就盯着这一句看 |
| ALPN / h2 | 对暗号时顺便约定讲哪种方言（HTTP/2 还是老的 1.1）。GitHub 边缘要求必须协商出 h2 |
| RST | 掐断电话：连接被中途强制挂断 |
| 黑洞 | 石沉大海：包发出去永远没有回音 |
| CONNECT 隧道 | 浏览器对 HTTPS 站点的方式：代理只负责"接通电话然后搬运加密箱"，箱里是什么看不见 |
| MITM（中间人） | 代理持有本地钥匙，把箱子拆开看明文、必要时换条路重发，再重新装箱给浏览器。需要浏览器信任代理自办的 CA 证书 |
| CA 证书 | 自办工作证。`ca.crt` 装进系统"受信任的根"后，浏览器才认代理现签的证书 |
| 指纹（JA3） | TLS 握手第一句的"笔迹"。本程序用 BoringSSL（Chrome 在用的 TLS 库），笔迹天然是 Chrome 同款 |

| 封锁 | 原理 | 本程序的绕法 |
|---|---|---|
| DNS 污染 | 查号台给假门牌 | 不查号，内置真 IP 表 |
| SNI 阻断 | 盯握手第一句的明文域名 | **伪装 SNI**：第一句写 `baidu.com`，证书按锚点验证；实测 Fastly 各段都吃这一套 |
| IP 黑洞 | 门牌本身被断路 | **串发换 IP**：按表逐个试，坏的垫底换下一个 |
| 风控 | 服务器故意回拦截页（403 restricted / 400 Whoa） | **gh_defuse**：本地认出拦截页，该 IP 垫底换下一个 |

## 本项目机制词

| 名词 | 大白话 |
|---|---|
| IP 节点 | 路由表里的一个出口：一组 IP + 伪装身份（`sni` 骗墙 / `verify` 锚点），`hosts` 列出它服务哪些域名；连接按 IP 复用，一条连接可服务多个域名 |
| 串发 | 排队逐个试，失败换下一个；大文件域例外——按字节切段给各候选并行跑（分段竞速），慢段让位 |
| 游标 | 每个域名记住"上次谁接通了"，下次从它开始试；其余候选按测速延迟从快到慢排 |
| 冷却 | 绕表全灭后 30 秒内快速失败，不反复烧表 |
| 熔断 | 内容域直连失败一次 120 秒内直接走镜像；镜像链全灭 60 秒内同域快速失败 |
| 流式直通 | 大请求体不进内存，边收边泵给上游，响应头一到立即回传 |
| 镜像链 | 每种资源的"复印店优先级名单"，串行逐家用；名单完全来自 routes.json，可加自部署镜像（支持拼接即可） |
| 分段竞速 | 大文件按字节切段：镜像一家一份，直连两份（它有两条通道），并行拉；同时来多个 Range 时按在途总字节 ÷（镜像数 + 2）定段大小，大区间先占段位、小区间保底一段，不设最小切片尺寸；慢段尾巴让给最快者；仅适用于支持 Range 的域（objects / release-assets） |
| 让位 | 慢段的尾巴按「接手划算才抢」的算术切给最快的源，缓冲里的字节一个不丢，交付线零缺口 |
| ECT 时间槽 | 大文件派发打分：手里的字节 ÷ 上一窗(500ms)实收 = 还需几个槽跑完，最少者胜；零历史垫底，有债零收（卡死）立即避开 |
| 预算 | 一次尝试最多等几秒（拨号 3s、响应 8s、镜像响应头 5s、流式响应头 1800s） |
| 首字节看门狗 | 电话通了但对方 8 秒不吭声 → 判死 |
| gh_defuse | 拦截页化解机制的名字 |
| 连接槽 | 按 IP 记，**每个 IP 有且只有 1 条 h2 连接**；第二条通道必须落在另一个 IP，候选不足两个空 IP 时只开一条。拨号完成即入库（同 IP 已有则丢弃新拨的、复用现成的），失效按连接 id 精确摘除 |
| 主副通道 | 主通道只开新坑：本 host 候选里已有通道的 IP 一律跳过，按游标优先串发；副通道起跑前先查「本 host 候选 ∩ 已有通道」，捡到就复用、不拨号，捡不到才跟主通道一样串发。两条腿共享「谁试过哪个 IP」，绝不重复试 |
| 拨号权 | 只给共享 IP（挂 2 个以上路由键或带通配键）配独立仲裁器：同一波申请按主站 > api > avatars 挑赢家，其余驳回换 IP；有先后就先到先得。握到通道建好即交棒给连接池，之后多个 host 随便复用；独占 IP 只留轻量「正在拨」标记 |
| 择优（EWMA） | 两条连接按实测耗时指数加权平均选快的用；两条速度接近时轮转各吃一半，差距明显才全押快的 |
| 遥测拦截 | GitHub 前端上报（`/_private/browser/*`、alive、collector）本地读掉回 204，不发往上游 |
| 伪装通道 | 所有受管域名统一用假 SNI 握手、按锚点验证书，业务路由靠 h2 `:authority`；真名 SNI 与 ClientHello 分片已整体退役 |
