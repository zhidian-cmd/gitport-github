Cloudflare Worker 部署教程（约 3 分钟，全程免费）

export default {
  async fetch(request) {
    const url = new URL(request.url);
    let rest = decodeURIComponent(url.pathname.slice(1)) + url.search;
    if (rest.startsWith("https:/") && !rest.startsWith("https://")) rest = "https:/" + rest;
    if (!/^https:\/\/([\w.-]+\.)*(github\.com|githubusercontent\.com|githubassets\.com|github\.io|githubapp\.com|build\.nvidia\.com|google\.com|google\.com\.hk|googleapis\.com|googleapis\.cn|gstatic\.com|gstatic\.cn|googleusercontent\.com|ggpht\.com)(\/|$)/.test(rest)) {
      return new Response("usage: /https://github.com/...", { status: 400 });
    }
    const headers = new Headers(request.headers);
    headers.delete("host"); headers.delete("cf-connecting-ip");
    headers.delete("cf-ipcity"); headers.delete("cf-ipcountry");
    headers.delete("cf-ray"); headers.delete("cf-visitor");
    headers.delete("cdn-loop"); headers.delete("x-forwarded-for");
    headers.delete("x-forwarded-proto"); headers.delete("x-real-ip");
    const target = new URL(rest);
    return fetch(target, { method: request.method, headers, body: request.body, redirect: "follow" });
  }
}

① Cloudflare 控制台 → Workers & Pages → Create → 选「Hello World」模板 → 起名并 Deploy；
② Edit Code → 全选删除，粘贴上面「复制 Worker 代码」的内容 → Deploy；
③ 回到概览页，你的 Worker 地址 = https://名字.你的子域.workers.dev；
④ 把地址粘贴到上方「我的镜像」→ 点「启动」。之后「启动/关闭」只增删 plans.json 链成员，地址注册表原位保留；
⑤ 建议绑定自有域名（Worker 设置 → 域和路由），抗 workers.dev 域名干扰；GitHub 看到的将全是 Cloudflare 的 IP。
