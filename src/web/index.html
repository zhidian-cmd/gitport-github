开机自启动

关闭窗口时缩到系统托盘

分流接管 = 免插件的可选项: 开关开启且代理运行中时, 本程序以 PAC 脚本接管系统代理, 只有对应站点经本代理加速, 其余流量不受影响; 全部关闭时不碰系统代理, 用插件/手动接入照常可用。代理停止时自动还原接管前的系统代理。

GitHub 分流接管

MITM 模式

伪装 SNI / 无 SNI 形态与拦截页化解仅在开启时生效, 作用与流程图见 README「MITM 模式」章节

镜像链校准

为有镜像的资源各维护一条镜像使用顺序链（串行取用，绝不并发）。两种校准都是后台任务：点击后即可关闭窗口进托盘，任务继续跑完，新链序自动保存，过程与报告见「运行日志」页。
• 大文件链（github.com / codeload / objects / release-assets）：5MB 真实下载竞速，四链串行、链内 11 家并发，一轮流量约 30-50MB，测的是下载吞吐
• 图片链（raw / gist / avatars / user-images / media）：响应头测速，约 1 分钟——图片小，首包时间就是主要成本
